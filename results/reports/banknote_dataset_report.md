## Model Performance Report: Banknote Authentication Dataset

### 1. Training Configuration

The model was trained using a custom "Multiple Kernel Learning Support Vector Machine" (MKL-SVM) framework with the following parameters:
	
- **Training Inputs:** PCA-reduced feature matrix and target labels. (from `0-3` PCA to `0-3` PCA with `100.0%` integrity).
    
- **Beta Optimization (MKL Layer):**
		
	- Beta Optimization Method: `"FISTA"`
        
    - Maximum Iterations: `20`
        
    - Tolerance: `1e-3`
    
- **SMO Solver (SVM Layer):**
	    
    - Regularization Parameter ($C$): `1`
        
    - Maximum Iterations: `10**5`
        
    - Tolerance: `1e-5`
	
- **Kernel Matrices (Kernel Layer):**
		
	- Kernel Centering: `True
	
	- Kernel Normalization: `True`

### 5. Key Observations & Technical Analysis

#### 1. Optimization Dynamics & Kernel Selection
	
- **Extreme Beta Sparsity via FISTA:** The outer MKL optimizer initialized with an equal weight distribution ($\beta_i = 0.2$ across 5 active kernels). "FISTA" rapidly drove the optimization toward a sparse solution, selecting the **"Rational Quadratic"** kernel as the sole contributor ($\beta = 1.0$) while zeroing out all other candidates.
    
- **Entropy Verification:** The recorded Weight Entropy of $-6.2139 \times 10^{-13} \approx 0$ quantitatively confirms complete sparsity, demonstrating that the "MKL" layer performed a hard selection rather than combining multiple smooth representations.
    
- **Feature Manifold Fit:** The selection of the "Rational Quadratic" kernel suggests that the feature space of the "Banknote Authentication" dataset benefits from an infinite mixture of "Gaussian RBF" kernels across different scale parameters, effectively handling complex non-linear variance in the "PCA" features.

#### 2. Implementation Parity & Decision Boundary
	
- **Near-Identical Predictive Performance:** The custom "MKL-SVM" achieved **96.71% Accuracy** and a **96.44% F1-Score**, matching Scikit-Learn's `SVC(kernel='precomputed')` almost perfectly (**96.71% Accuracy**, **96.41% F1-Score**). This validates the numerical stability and correctness of the custom kernel transformation pipeline (centering and normalization) and inner "SMO" solver.
    
- **Enhanced Model Sparsity:** The custom SMO implementation achieved a slightly more compact decision boundary, selecting **257 support vectors** (~23.4% of the dataset) compared to Scikit-Learn / LIBSVM's **276 support vectors** (~25.1%). This indicates efficient margin optimization without sacrificing generalization.

#### 3. Computational Bottlenecks & Execution Analysis
	
- **Inner Loop Dominance:** The outer "MKL" layer converged efficiently in just **2 iterations** (total runtime ~1 min 6 sec). The outer "FISTA" updates required minimal runtime, whereas the inner "SMO" solver consumed the vast majority of compute time (**58.26 seconds** across 5,951 inner iterations on the final pass) to enforce strict dual variable ($\alpha$) convergence within the $10^{-5}$ tolerance.
    
- **Alignment Metric Assessment:** The "Kernel Target Alignment" score settled at **0.1143**. While relatively low in absolute terms, it proved sufficient for the "MKL" layer to isolate the single kernel matrix with the highest directional alignment to the target labels.
